TRADITIONAL APPROACH

Starting With a Simpler Model

Before testing more complex machine learning methods, this study uses a traditional statistical method: linear regression.

Linear regression is a simple and easier way to find whether the financial features in the dataset have useful information about future stock returns.

THE STARTING POINT

What Is Linear Regression?

Linear regression is a statistical method that models the relationship between one or more input variables and an outcome. The model uses financial features such as previous returns, volatility, trading volume, moving averages, momentum, and market returns to predict future stock returns.

WHY USE IT?

A Useful Baseline

Simple

Linear regression is simpler compared with the machine learning models tested later in the study. This makes it useful as a starting point for comparison.

Interpretable

The model provides a way to look at the relationship between the input features and predicted returns without relying on a complex structure.

Fast

Linear regression can be trained and used for predictions quickly. This makes it useful when comparing prediction performance with models that require longer computation.

WHAT THE MODEL USES

Financial Features

The regression model does not try to predict stock prices directly. It uses financial features to estimate future stock returns. These features were chosen to represent recent price behavior, volatility, trading activity, momentum, and broader market movement.

Previous Returns

Recent stock returns give information about how the stock has moved over time.

Volatility

Volatility measures how much a stock's returns have varied and helps show recent changes in market risk.

Trading Volume

Trading volume represents the amount of market activity surrounding a stock and can show information about participation and demand.

Moving Averages

Moving averages show recent price trends and can help find the direction of a stock's movement over time.

Momentum

Momentum sees recent price movement and helps measure whether a stock has been trending upward or downward.

Market Returns

Market-level returns give broad information about overall market movement that may affect individual stocks.

MULTIPLE TIME HORIZONS

The model was tested across more than just the next trading day.

Predictions were evaluated at seven different horizons: 1 day, 5 days, 10 days, 1 month, 6 months, 1 year, and 5 years.This lets the study examine whether using a simple statistical model changes as the prediction window becomes longer.

The same horizons were used when comparing linear regression with Random Forest, XGBoost, and neural networks.

NEXT STEP

What Happens When the Model Gets More Complex?

Linear regression is an important baseline, but it assumes a simple relationship between the features and future returns. Financial markets can have nonlinear relationships and interactions that a basic regression model might not be able to see.

The next step in this study is to test whether machine learning models can find additional patterns and improve prediction performance.
