MACHINE LEARNING

What Happens When the Models Get More Complex?

After finding a baseline with linear regression, the study tests machine learning models that can find more complicated relationships between financial features and future returns.

Random Forest, XGBoost, and a neural network were evaluated using the same prediction horizons and financial features.

THE METHODS

Beyond Linear Relationships

Machine learning models can find patterns in data without every relationship needing to be specified in advance. The goal was to determine whether added model complexity could improve stock return predictions compared with the traditional linear regression baseline.

THREE MACHINE LEARNING MODELS

Different Ways to Find Patterns

01

Random Forest

Random Forest combines decision trees and uses their combined predictions to make a final result. This lets the model capture nonlinear relationships while decreasing the influence of a single decision tree.

02

XGBoost

XGBoost builds decision trees sequentially, with each new tree trying to improve the errors made by the previous trees. This can find complex patterns while being efficient to train.

03

Neural Network

Neural networks use layers of nodes to learn patterns in the data. They can represent complex relationships, but they also need more computation and can be more difficult to interpret.

THE REAL QUESTION

Does greater complexity lead to better predictions?

A more complicated model is not necessarily a better model. Each machine learning approach was evaluated using the same financial features and prediction horizons so that performance could be compared consistently.

The study measures error, explanatory power, directional accuracy, and computational time to understand both prediction performance and the cost of model complexity.

MODEL COMPLEXITY

More Complexity Comes With Cons

Prediction Performance

Models were compared using MAE, RMSE, and R² to measure how closely predictions matched actual stock returns.

Directional Accuracy

The study also measures how often each model correctly predicts whether a stock's return will be positive or negative.

Computational Time

Training and prediction times were recorded to find whether improvements in performance came with additional computational cost.

WHAT THE DATA SHOWS

Complexity Did Not Always Mean Better Performance

The results show that model performance depends on the prediction horizon. Linear regression performed best at shorter and medium horizons, while XGBoost had the highest R² and lowest RMSE of the tested models at the 5-year horizon.

This shows that the relationship between model complexity and prediction performance is not just about using the most complicated model. The time horizon being predicted also has a form of significance.
