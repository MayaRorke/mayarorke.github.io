What Goes Into a Stock Prediction?

Stock prediction models use different types of information to find patterns in historical market data. This page explores the features, prediction horizons, and models used in this project.

INPUT FEATURES

What Does the Model Look At?

The models in this project use historical market information as predictors. These features help the models find patterns that could be related to future stock returns.The historical data used in this project comes from Yahoo Finance .

Returns

Historical returns show how a stock has performed over previous periods and give information about recent price movement.

Volatility

Volatility measures how much prices have changed over time. Higher volatility can make future returns more difficult to predict.

Trading Volume

Trading volume represents the amount of activity in a stock. Changes in volume can have information about market participation.

Moving Averages

Moving averages smooth historical prices and help find longer-term trends in the data.

Momentum

Momentum features measure recent price movement and can help models find whether a stock has been trending upward or downward.

Market Returns

Market-level returns have broader information about overall market conditions that may affect individual stocks.

MODEL COMPLEXITY

Four Different Approaches

The project compares models with different levels of complexity. This helps determine whether more complicated machine learning method have better predictions than simpler statistical models.

Linear Regression

A statistical method that models the relationship between input variables and future returns using a linear equation.

Random Forest

A machine learning model that combines decision trees to find nonlinear relationships within the data.

XGBoost

A gradient boosting algorithm that builds decision trees sequentially to improve predictions and capture more complex patterns.

Neural Network

A machine learning model capable of learning complexrelationships between multiple financial features.
