THE BIG QUESTION

Can artificial intelligence actually predict the stock market?

Predicting stock returns is difficult because financial markets are constantly changing. Investors and researchers use historical prices, trading volume, returns, and other financial information to try to understand what might happen next.

This website explores how traditional statistical models and machine learning methods can be used to make those predictions.

ABOUT THIS PROJECT

What Are We Trying to Predict?

The goal of this project is to explore how different statistical and machine learning models can be used to predict short-term stock returns. Instead of simply asking whether a stock price will go up or down, the project examines how well models can estimate future returns across different prediction horizons.


The models use financial information from historical market data to identify patterns that may be useful for prediction. By comparing different approaches, we can examine whether increasing model complexity actually leads to better predictions.

THE BIG QUESTION

If AI can identify patterns in financial data, can it actually beat the market?

Machine learning can process large amounts of information and identify relationships that may be difficult to find using traditional methods. However, financial markets are unpredictable, and finding patterns in historical data does not necessarily mean those patterns will continue in the future.


This project compares different approaches to see how their predictions perform.
